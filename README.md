# proyecto-integrador-SINFOG
SINFOG es un prototipo integral de gestión empresarial desarrollado para el primer parcial de la asignatura Aplicaciones de Tecnologías Web. El sistema centraliza 
las operaciones de Mantenimiento, Biblioteca, Nómina y Contabilidad, permitiendo que la información fluya automáticamente entre departamentos para optimizar 
la toma de decisiones.
